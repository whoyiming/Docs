# 中心主题：AI研发工程师岗位技能图谱
## 1. 语言基础
### 岗位能力项
- 编程语言：Python / Java / C++ / Go / Rust / JavaScript / TypeScript
- 数据结构与算法：数组/链表/树/图/排序与搜索、动态规划/贪心算法、时间复杂度分析
### 分层技能点
- 初级：
  了解公司内部基础编码规范与协作流程
  能使用公司推荐的AI Coding开发工具与环境完成基本任务
  能在指导下编写简单的单元测试
  能了解AI辅助学习技术文档
- 中级：
  熟练应用公司编码规范与CI/CD流程
  高效使用AI Coding工具，评估AI生成代码的正确性与安全性
  自主设计并实现算法核心逻辑的单元测试
  规范化撰写技术方案文档、接口说明及故障排查报告
  善用AI提升开发质量与效率
- 高级：
  主导制定优化团队/项目级编码规范
  深度集成AI Coding能力到研发工作流中
  构建高覆盖率、高维护成本的自动化测试体系
  输出标准化技术文档
  评估并引入前沿研发工具链
### 推荐课程
- 《快速上C++：数据结构与算法》
- 《零基础学Python》
- 《Linux高性能36讲》
- 《Rust实战开发教程》

## 2. 机器学习
### 岗位能力项
- 监督学习：线性回归/逻辑回归、决策树/随机森林/ XGBoost/LightGBM
- 无监督学习：K-Means聚类、PCA降维、异常检测算法
- 强化学习：Q-Learning、DQN、Policy Gradient、Actor-Critic、DDPG / A3C
### 分层技能点
- 初级：
  理解Transformer架构的基本组件及LLM基本原理
  能使用Hugging Face Transformers库加载预训练模型并完成常见任务
  了解LoRA微调的基本思想，能在指导下使用PEFT库进行LoRA微调
  了解MLOps的核心概念，对强化学习有基本认知
- 中级：
  熟练应用LoRA及其变体进行高效微调
  能根据任务特性选择适配模型，并评估微调后模型的泛化性与鲁棒性
  理解MLOps的实现细节，能在开源框架中进行修改
  能将RL思想用于优化AI产品体验
  具备模型压缩与量化意识，清楚模型的能力边界
- 高级：
  深入理解Transformer的演进与瓶颈
  主导高效微调方案的调研与落地实施
  具备LLM模型训练与调优实战经验
  将RL融入AI系统闭环
  能够横向对比LoRA、QLoRA、Adapter、Prefix-tuning等方法，结合业务需求进行选型
### 推荐课程
- 《人工智能基础课》
- 《机器学习40讲》
- 《强化学习快速入门与实战》
